# 使用与平台边界

## 连接准备

被控端是 Android，控制端是 iPhone / iPad。被控 Android 不需要安装本项目 App；连接时会把带会话标识的服务临时放到 `/data/local/tmp/`，结束后清理。

Android 11+ 推荐使用无线调试：在 App 点击「无线调试配对」。

- **二维码**：iOS 生成二维码，Android 在「开发者选项 → 无线调试 → 使用二维码配对」中扫码。App 通过 Bonjour 找到扫码后启动的配对服务，自动完成配对。
- **配对码**：Android 打开「使用配对码配对」，把弹框中的地址、配对端口和 6 位配对码填到 App。保持弹框打开，配对成功后再关闭。
- 配对成功后使用无线调试主页面的**连接端口**，它与配对端口不同。App 会自动发现同一地址的连接服务；网络屏蔽 Bonjour 时可手动填写。
- 配对身份保存在 Keychain，后续连接会自动进行 ADB STLS / TLS 1.3 握手。Android 更换连接端口后需更新配置。
- 「设置 → 本机名称」默认使用系统提供的设备名，可手动修改；新配对时将此名称传给 Android。为兼容 Android 的设备列表，名称中的空白转为下划线，设置中可预览最终名称。旧记录的名字不会仅因本机设置变化而自动改名。

二维码需要双方处于可互通的局域网，并允许 iOS 本地网络访问。配对码允许手工填写可达地址。配对失败会提示，取消或关闭页面会终止本机配对连接；二维码刷新会生成新秘密，配对码和二维码秘密均不写入配置或日志。

也支持经典 TCP ADB：Android 打开 USB 调试，用电脑运行 `adb tcpip 5555`，填写设备地址和端口，首次在 Android 确认调试授权。

设备必须网络可达。跨网络可使用 EasyTier、Tailscale 等组网工具，但它们不是项目依赖。经典 TCP ADB 不负责加密传输；请使用可信局域网或加密的组网通道，不把调试端口直接暴露到公网。

## 配置与远控

配置包含主机、端口、画质和控制选项。保存同名配置会更新该配置；修改主机或端口后可保存为另一个配置。切换弹框先选中，再确认；删除需再次确认。

进入远控后，竖屏底部提供返回、Home、最近任务，左右分别为状态和键盘 / 设置。横屏将状态放在左侧，操作按钮竖排在右侧，保留系统安全边距。应用隐藏状态栏并保留顶部安全区域。

边缘操作按**远控画面的边缘**判断，也支持从画面旁的黑边向内滑入：左右返回、底部 Home、顶部展开快捷设置。中间区域的滑动作为普通触摸发送。多点触控时取消单指边缘手势判定。

iOS 的系统手势只能通过公开 API 请求延迟触发，无法保证永久屏蔽控制中心、通知中心或 Home 手势。使用安全区域和远控画面边缘，避免从本机物理屏幕边缘反复滑动。

## 键盘

虚拟键盘为六行 QWERTY。前两行是 Esc、Tab、方向、Ctrl、Alt、Win 等控制键；中间三行字母，底行包含符号切换、句点、空格、Fn 和回车。上滑字母输入右上角符号，下滑输入大写。修饰键单击作用于下一次按键，长按锁定，再点取消。Fn + 顶行字母发送 F1–F10，另外提供 F11/F12、Menu 和 Insert。

支持外接硬件键盘。文字输入弹框通过 Android 剪贴板粘贴，适合非 ASCII 文字；单次上限 64 KiB。系统剪贴板只在用户点击「粘贴」时读取。

## 声音、方向与仅观看

- 远端系统声音默认播放，本机麦克风转发默认关闭，两者独立开关。
- 远端声音要求 Android 11 或更新版本；Android 11 可能需要屏幕解锁。受版权保护或禁止捕获的声音不能保证转发。
- 麦克风转发使用 Android 系统的音频路由能力。并非所有系统 / 厂商 / 目标 App 都支持，失败会提示并关闭对应开关。用户启用后才请求本机录音权限。
- 方向同步可关闭；设置弹框也可手动向左 / 向右旋转。关闭同步或断开后恢复原方向设置。
- 保持唤醒控制的是 Android 的充电时保持唤醒设置，关闭或断开时恢复。
- 仅观看关闭触摸、键盘、麦克风和方向修改。声音播放可单独使用。

进入后台会主动结束连接并恢复远端设置，避免看不到画面时仍持续录音或占用被控端。网络被强制中断时清理依靠远端 shell 结束；极端情况下可重新连接后检查设备方向 / 唤醒设置和本项目遗留临时文件。

## 当前限制

iOS 首版暂不提供 USB ADB 直连、后台远控、文件传输和远端到本机的自动剪贴板同步。首轮验收主要使用 iPhone 模拟器与 Android 14 AVD；真机音频路由、蓝牙设备、iPad 各尺寸及不同厂商 Android 仍需验证。
